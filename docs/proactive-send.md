# 主动分享与主动私信

本分支在上游 [LockyBee/dsh-douyin-agent](https://github.com/LockyBee/dsh-douyin-agent) 上增加两个由模型直接调用的工具。维护者是「肥鱼博士」。包名是 `dsh-douyin-browser-feiyu`。不要发布到 npm，也不要向上游开拉取请求。

上游原有的 `douyin_forward_video` 不变：没有本机按钮授权时，仍然只返回「请在本机控制台选择这位好友并点击转发」。观看过程中的自主分享也仍只在已有许可好友里挑当前作品。

## 工具

| 工具 | 做什么 |
| --- | --- |
| `douyin_share_video` | 通过抖音网页官方分享面板，把作品卡片发给指定好友或会话 |
| `douyin_send_message` | 给指定的人发一条文字私信 |

分享的 `recipient` 可以是会话 ID（`conv:` 加 64 位十六进制）、抖音号、`sec_uid` 或 `https://www.douyin.com/user/…` 主页链接。`url` 与 `videoId` 都可以不填，不填就用当前正在看的作品；两个都填时必须是同一个作品。

私信的 `text` 为 1 到 1000 字。收件人四选一：`recipientId`、`douyinId`、`profileUrl`、`secUid`。已经有会话就在该会话里发。没有会话时打开主页，核对抖音号或 `sec_uid`，只在唯一的「私信」按钮上点一次，再核对打开的个人会话后填写发送。群聊不走这条主动私信。

发送沿用现有稳定身份和官方面板按钮核对。对不上、按钮不唯一、页面在登录或验证时，不点击发送。

## 默认配置

设置在插件和软件的「好友互动 → 主动发送」。

| 项 | 默认 | 范围 |
| --- | --- | --- |
| 允许模型主动发送 | 关闭 | 开 / 关 |
| 只发给允许名单 | 开启 | 可在设置里关掉 |
| 每日主动分享 | 3 | 1–20 |
| 每日主动私信 | 5 | 1–20 |
| 两次发送最小间隔 | 60 秒 | 10–3600 秒 |

分享和私信分开计每日次数，间隔是两种发送共用的。次数按上海日期计算。没有真正点到发送的失败会退回这一次占用；已经点击但回执不确定的不退回，并禁止对同一对象、同一作品或同一条正文自动再发。

用户可以在设置里把待核对记录标成「已发出」或「未发出」。这只改本地记录，不会重发。

允许名单里的每一行是会话 ID、抖音号、`sec_uid` 或主页链接。名单开启且为空时，两个工具都会拒绝。抖音号按不区分大小写保存。

## 日志

每次调用在本机状态目录写 `proactive-send-log.json`，字段只有时间、对象、类型和结果。不写私信正文、Cookie、密钥或请求头。配置和待核对标记在 `proactive-send.json`，其中的内容标记是哈希，不是原文。

## 风控

这两个动作都会在已登录的抖音网页里替你点官方按钮。平台可以限流、要求验证码或限制账号。建议用小号，先保持允许名单开启，确认对象后再打开总开关。网页结构变化时，工具会停在「未发送」或「结果未确认」，不要改用未公开接口、坐标连点或重复调用去补发。

本仓库的自动化测试覆盖开关、名单、次数、间隔、退次、不确定不重发和日志脱敏。没有在真实抖音账号上点过分享或私信。
